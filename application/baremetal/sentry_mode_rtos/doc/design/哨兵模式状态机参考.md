# 哨兵模式状态机参考

**更新日期**: 2026-04-27
**处理器**: NA900 (32位 RISC-V, 带 DSP 扩展)

---

## 状态定义

| 状态 | 枚举值 | 说明 |
|------|--------|------|
| `STATE_SLEEP` | 0 | 深度休眠，CPU 16MHz，摄像头关闭，等待定时器唤醒 |
| `STATE_LEVEL1_MONITORING` | 1 | L1 低功耗监控，5 秒/帧，SSD MobileNet 人形检测 |
| `STATE_LEVEL2_TRACKING` | 2 | L2 高帧率跟踪，200ms/帧(5 FPS)，危险动作识别 |
| `STATE_LEVEL3_CONTINUOUS` | 3 | L3 持续监控+录像，200ms/帧(5 FPS)，最长 60 秒 |
| `STATE_ALARM_TRIGGERED` | 4 | 警报触发（保留枚举，当前未使用） |
| `STATE_ERROR` | 5 | 错误状态（保留枚举，当前未使用） |

---

## 状态转换

### SLEEP → LEVEL1

| 维度 | 说明 |
|------|------|
| **触发条件** | 定时器唤醒（`LEVEL1_INTERVAL_MS = 5000ms`） |
| **动作** | 1. `camera_init()` — 初始化摄像头 |
| | 2. `set_cpu_frequency(160000000)` — 恢复 160MHz |

### LEVEL1 → SLEEP

| 维度 | 说明 |
|------|------|
| **触发条件** | 未检测到人（`result != 1 || conf <= 0.6`） |
| **动作** | 1. `camera_power_down()` — 关闭摄像头 |
| | 2. `set_cpu_frequency(16000000)` — 降至 16MHz |
| | 3. `enter_low_power_mode(5000)` — 进入 WFI 休眠 |
| **恢复动作** | 唤醒后：`camera_init()` + `set_cpu_frequency(160000000)` |

### LEVEL1 → LEVEL2

| 维度 | 说明 |
|------|------|
| **触发条件** | 连续 2 帧检测到人（`result==1 && conf>0.6 && s_consecutive_detections>=2`） |
| **确认机制** | 连续帧确认，防止单帧误报 |
| **动作** | 1. `set_cpu_frequency(160000000)` — 高性能模式 |
| | 2. `ai_switch_mode(MODE_LEVEL2)` — 切换到 L2 推理模式 |
| | 3. `g_system_state = STATE_LEVEL2_TRACKING` |
| | 4. 初始化 L2 计时器：`s_level2_start_time = 0` |

### LEVEL2 → LEVEL3

| 维度 | 说明 |
|------|------|
| **触发条件** | 检测到危险动作（`action != ACTION_NORMAL && conf > 0.6`） |
| **动作** | 1. `g_system_state = STATE_LEVEL3_CONTINUOUS` |
| | 2. `xQueueSend(CMD_LEVEL2_TO_L3)` — 通知 Recorder |
| | 3. **`xQueueSend(CMD_START_RECORDING)`** — 开始录像 |
| | 4. `xTaskNotifyGive(task_alarm)` — 触发声光警报 |

### LEVEL2 → LEVEL1

#### 人员离开

| 维度 | 说明 |
|------|------|
| **触发条件** | `s_person_present == false && 距上次检测 > 10 秒` |
| **动作** | 1. `xQueueSend(CMD_LEVEL2_TIMEOUT)` — 通知 Recorder |
| | 2. `ai_switch_mode(MODE_LEVEL1)` |

#### L2 超时

| 维度 | 说明 |
|------|------|
| **触发条件** | 进入 L2 超过 `LEVEL2_MAX_DURATION_MS = 10 秒` 未检测到危险 |
| **动作** | 1. `xQueueSend(CMD_LEVEL2_TIMEOUT)` — 通知 Recorder |
| | 2. `ai_switch_mode(MODE_LEVEL1)` |

> **说明**：L2→L1 不发送 `CMD_STOP_RECORDING`。录像仅在 L3 阶段开启，L2 阶段无录像。

### LEVEL3 → LEVEL2

| 维度 | 说明 |
|------|------|
| **触发条件** | 危险解除且人还在（`s_normal_count >= 15帧 && s_no_person_count < 15帧`） |
| **确认机制** | 连续 15 帧（3 秒）检测到 ACTION_NORMAL |
| **动作** | 1. **`xQueueSend(CMD_STOP_RECORDING)` + 50ms delay** |
| | 2. `xQueueSend(CMD_LEVEL3_TO_L2)` — 通知 Recorder |

### LEVEL3 → LEVEL1

#### 人员离开

| 维度 | 说明 |
|------|------|
| **触发条件** | 距上次检测 > 15 秒 && 连续 30 帧未检测到人 |
| **确认机制** | `s_no_person_count > 30`（6 秒） |
| **动作** | 1. **`xQueueSend(CMD_STOP_RECORDING)` + 50ms delay** |
| | 2. `xQueueSend(CMD_LEVEL3_TO_L1)` — 通知 Recorder |
| | 3. `ai_switch_mode(MODE_LEVEL1)` |

#### L3 超时（硬上限）

| 维度 | 说明 |
|------|------|
| **触发条件** | 进入 L3 超过 `LEVEL3_MAX_DURATION_MS = 60 秒` |
| **安全机制** | 防止危险持续时系统永不退出 |
| **动作** | 1. **`xQueueSend(CMD_STOP_RECORDING)` + 50ms delay** |
| | 2. `xQueueSend(CMD_LEVEL3_TIMEOUT)` — 通知 Recorder |
| | 3. `ai_switch_mode(MODE_LEVEL1)` |

## 录像触发点

| 时刻 | 命令 | 
|------|------|
| L2 → L3 | `CMD_START_RECORDING` |
| L3 → L2 | `CMD_STOP_RECORDING` |
| L3 → L1 | `CMD_STOP_RECORDING` |

---

## 警报任务

| 维度 | 说明 |
|------|------|
| 触发 | AI 在 L2→L3 时 `xTaskNotifyGive(task_alarm)` |
| 执行 | `trigger_alarm()` — 蜂鸣器 + 车灯闪烁 |
| 持续时间 | 30 秒 |
| 结束 | `stop_alarm()` — 关闭蜂鸣器和车灯 |
| 状态管理 | **不参与**。Alarm 只管硬件，不改 `g_system_state` 和 AI 模式 |

---

## 关键时间参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `LEVEL1_INTERVAL_MS` | 5000ms | L1 检测间隔 |
| `LEVEL2_FRAME_PERIOD_MS` | 200ms | L2/L3 推理节拍 |
| `LEVEL2_HISTORY_FRAMES` | 8 帧 | 时序输入帧数 |
| `LEVEL2_MAX_DURATION_MS` | 10000ms | L2 无危险超时 |
| `LEVEL3_MAX_DURATION_MS` | 60000ms | L3 硬超时上限 |
| `LEVEL3_PERSON_LOST_TIMEOUT_MS` | 15000ms | L3 人员离开超时 |
| `s_normal_count` 阈值 | 15 帧 | 危险解除确认（3 秒） |
| `s_no_person_count` 阈值 | 30 帧 | 人员离开确认（6 秒） |
| L2 人员离开超时 | 10000ms | 硬编码 |
| 警报持续 | 30000ms | 硬编码 |

## 状态机流图

```
┌──────────────────┐
│      SLEEP       │  CPU 16MHz, 无摄像头
│   唤醒: 5秒定时   │
└────────┬─────────┘
         │ 定时器唤醒
         ▼
┌──────────────────┐
│   LEVEL1 (L1)    │  5秒/帧, 224×224
│  低功耗人形检测   │  SSD MobileNet
└──┬───────────┬───┘
   │           │
   │ 连续2帧   │ 无人
   │ 检测到人  │
   ▼           ▼
┌─────────────┐   SLEEP
│ LEVEL2 (L2) │   (WFI 5秒)
│ 200ms, 5FPS │
│ 64×64, 时序 │
└──┬──────┬───┘
   │      │
   │ 危险 │ 人员离开>10s
   │ 检测 │ 或 超时>10s
   ▼      └──────────→ L1
┌──────────────────┐
│   LEVEL3 (L3)    │  200ms, 5FPS
│  持续监控+录像    │  ├ START_RECORDING
│  最长 60 秒      │  └ 触发 Alarm
└──┬──────────┬────┘
   │          │
   │ 危险解除 │ 人员离开>15s
   │ +人在    │ 或 超时>60s
   ▼          │
  L2          └──────────→ L1
 (STOP_REC)                 (STOP_REC)
```
